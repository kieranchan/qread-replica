## 未移植（原因）

- **云端仓库（WebDAV 书仓）**：cloud_setting_page 的 启用云端仓库 / 同步云端仓库 / 从云端书仓下载（0xf7e960、0xfb024c）。依赖
  原版的 WebDAV 书籍同步协议，复刻的本地书在手机上，暂无需求。
- **后端进度 `/saveBookProgress`**：原版在绑定轻阅读后端时上报，`isnew` 字段语义未验证，不向第三方后端发猜测的数据。
- **导出方式 · 上传服务器（链接 7 天有效）**（0x545f8c / 0xf836a0）：复刻服务器没有对应的分享上传接口；现在导出为文件。
- **连载中 / 已完结 标签**（0x5b340c）：复刻的 Book 模型没有完结状态字段，书源也不统一提供。
- **启动图**（主题编辑 0x6b8e50）：iOS 启动画面无法在运行时更换。
- **轻阅读后端 WebSocket 心跳 / 连接状态**（main_page HEART_CHECK、bookshelf 0x543004）：仅在绑定后端时有意义。
- 大量日志 / 计时字符串（`任务执行时间`、`_calculatePages 总耗时` 等）不是行为，不移植。
